# design-sync notes — CS Investor Hub UI

Project: https://claude.ai/design/p/e4b1ca33-2419-4789-897d-4e973313c086

## Repo quirks this sync had to work around

- **The package has no build and no TypeScript.** `@packages/shared` exports `src/`
  directly. The converter's synth entry re-exports all 82 source files (pages,
  hooks, data-coupled screens), so `packages/shared/ds-entry.js` is a hand-written
  entry that pins the scoped surface. Add a component there, not to the config.
- **`.d.ts` discovery finds nothing** (no types in the repo), so `componentSrcMap`
  in the config is the authoritative component list — 109 names generated from the
  entry's re-exports. Regenerate it when `ds-entry.js` changes.
- **`--entry` is resolved relative to the CWD, not the package**, and the converter
  looks for `package.json` next to it. That is why the entry lives inside
  `packages/shared/` rather than under `.design-sync/`.
- **`cfg.tsconfig` is resolved relative to the package dir**, which is the
  `node_modules/@packages/shared` symlink. `packages/shared/tsconfig.json` exists
  purely so the `@shared/*` alias (187 imports) resolves for esbuild.
- **The app's compiled CSS is not enough.** Tailwind only emits utilities the app
  actually uses, so `bg-accent` and `text-card-foreground` were missing and any
  design using them would render unstyled. `cfg.buildCmd` compiles
  `.design-sync/css/ds.css` (app theme + `.design-sync/css/safelist.html`,
  ~1365 token utilities) instead. Extend the safelist when tokens are added.
- **Manrope was never declared.** The four woff2 files sit in
  `apps/web/src/assets/fonts/` but `apps/web/src/fonts.css` is EMPTY and nothing
  imports them — the app itself only shows Manrope if the OS has it installed.
  `packages/shared/ds-fonts.css` declares them for the DS. **The app bug is still
  open.**

## Preview conventions

- Sub-components that cannot render alone (`TableCell`, `DialogHeader`,
  `SelectGroup`, `DropdownMenuLabel`, `Chart*`, …) have previews that render the
  **parent composition**. `cfg.overrides.<Name>.skip` does NOT work for this — it
  takes a list of story names and only applies to authored previews.
- Overlays (`Dialog`, `AlertDialog`, `Select`, `DropdownMenu`, `Tooltip`) need
  `cardMode: "single"` plus a viewport, and their content needs
  `className="relative left-auto top-auto translate-x-0 translate-y-0"` so the
  centred fixed positioning does not escape the card.
- **recharts animates on mount**, so the screenshot catches a half-drawn area.
  Every `<Area>` in the chart previews sets `isAnimationActive={false}`.
- Content is domain-realistic on purpose (real skin names, EUR prices, ROI
  percentages) — the design agent imitates these cards.

## Known render warns

- 51 components ship the typographic floor card (unauthored previews). Deliberate:
  they are plumbing (`*Portal`, `*Trigger`, `ScrollBar`, `ChartStyle`) or leaf
  parts already shown inside a parent composition. Authorable on any re-sync.

## Re-sync risks

- `packages/shared/ds-styles.css` and `.design-sync/css/out.css` are generated by
  `cfg.buildCmd`. If a token is added to `apps/web/src/index.css` but not to the
  safelist, its utilities silently will not ship.
- `componentSrcMap` is a snapshot. A component added to `ds-entry.js` without
  regenerating the map is bundled but gets no card and no `.d.ts`.
- Grades were carried forward 49/49 on the final run. A cleared grade on a
  no-change re-sync means a nondeterministic input — chase it.
- Of the 49 authored previews, five were inspected image-by-image (Card, Table,
  ChartContainer, Select, Separator). The rest passed the mechanical render check
  (109/109 non-blank, non-thin, variants distinct) but were not individually
  eyeballed. A human pass over `.review.html` is still owed.
